# Site Informativo - Associação dos Congadeiros de Machado/MG

Este projeto é um site informativo sobre a **Associação dos Congadeiros da cidade de Machado/MG**, desenvolvido com o objetivo de divulgar a história, eventos e tradições culturais da congada local.

## Sobre o Projeto

O projeto foi elaborado no âmbito da disciplina de **Projeto e Extensão**, com fins educativos e de valorização do patrimônio cultural. O site apresenta informações relevantes sobre a associação, sua história, datas comemorativas e uma galeria de imagens e vídeos.

## Estrutura do Projeto

```
.
├── assets/          # Mídias (imagens, vídeos e outros recursos)
├── css/            # Arquivos de estilização (CSS)
├── js/             # Scripts de interatividade (JavaScript)
├── pagesHTML/      # Páginas do site em HTML
└── .gitignore      # Arquivo para ignorar arquivos no controle de versão
```

## Tecnologias Utilizadas

- **HTML5**: Estruturação das páginas.
- **CSS3**: Estilização e layout do site.
- **JavaScript**: Funcionalidades interativas.

## Como Executar o Projeto

1. Clone este repositório:
   ```bash
   git clone <URL_DO_REPOSITORIO>
   ```

2. Acesse o diretório do projeto:
   ```bash
   cd nome-do-projeto
   ```

3. Abra o arquivo `index.html` em seu navegador.
